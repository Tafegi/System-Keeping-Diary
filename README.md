# System Keeping Diary

Особистий щоденник у Telegram. У приватному чаті з ботом можна записувати думки й переглядати останні записи.

**Бот у Telegram:** `@system_keeping_diary_bot`

## Команди

- `/start` — показати підказку.
- `/new` — створити запис із заголовком і текстом.
- `/list` — переглянути до п’яти останніх записів.

## Як додати запис

Надішли заголовок і текст одним повідомленням, як у прикладі:

```text
/new Перша репетиція
Сьогодні записав гітарну партію.
```

Бот відповість «Збережено». Надішли `/list`, щоб побачити свій запис.
